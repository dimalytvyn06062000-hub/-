# Infinity Gauntlet — Forge 1.20.1

Мод даёт 6 отдельных Камней Бесконечности и Перчатку Бесконечности.

## Как получить .jar

### Вариант А — без установки ничего (GitHub)
1. Создайте репозиторий на github.com и загрузите в него ВСЁ содержимое этой папки
   (включая скрытую папку `.github`).
2. Вкладка **Actions** → **Build mod** → дождитесь зелёной галочки.
3. Откройте завершённый запуск → внизу **Artifacts** → `infinitygauntlet-jar` → скачайте.
   Внутри будет `infinitygauntlet-1.0.0.jar`. Кладёте в папку `mods` (Forge 1.20.1).

### Вариант Б — локально
1. Установите JDK 17 и Gradle 8.1.1 (gradle.org/releases).
2. В папке проекта: `gradle build`
3. Готовый файл: `build/libs/infinitygauntlet-1.0.0.jar`

## Игровые механики
Камень (отдельный предмет): ПКМ — способность. Пока лежит в инвентаре — пассивный эффект.
| Камень | ПКМ | В инвентаре |
|---|---|---|
| Силы | взрыв в точке взгляда | Сила |
| Пространства | телепорт | Скорость |
| Реальности | 3 молнии | Огнестойкость |
| Души | полное исцеление | Регенерация |
| Времени | замедление мобов + ваше ускорение | Спешка |
| Разума | мобы светятся и дерутся | Ночное зрение |

Перчатка: Shift+ПКМ — сменить камень, ПКМ — способность (все 6 + Щелчок: исчезает ~50% мобов в радиусе 30),
в инвентаре — пассивки всех шести камней.

## Крафты
- Каждый камень: `GDG / DCD / GDG` — G золотой слиток, D алмаз, C центр:
  Сила — аметистовый блок, Пространство — лазуритовый блок, Реальность — блок редстоуна,
  Душа — золотой блок, Время — изумрудный блок, Разум — светокамень.
- Перчатка: `PSR / UNT / BMB` — P/S/R/U/T/M камни Силы/Пространства/Реальности/Души/Времени/Разума,
  N звезда Нижнего мира, B незеритовый блок.
Файлы рецептов: `src/main/resources/data/infinitygauntlet/recipes/`.
Креатив: вкладка «Infinity Gauntlet» или `/give @s infinitygauntlet:power_stone`.
